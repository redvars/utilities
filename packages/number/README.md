# @utility/number

[![npm](https://img.shields.io/npm/v/@utility/number.svg)](https://www.npmjs.com/package/@utility/number)
[![License](https://img.shields.io/github/license/redvars/utilities.svg?label=License)](../../LICENSE)

Collection of number utility functions

## Install

```shell
npm install @utility/number
```

## Usage

```typescript
import { random } from "@utility/number";

random(10, 20);
// => 14
```
