# @utility/file

[![npm](https://img.shields.io/npm/v/@utility/file.svg)](https://www.npmjs.com/package/@utility/file)
[![License](https://img.shields.io/github/license/redvars/utilities.svg?label=License)](../../LICENSE)

Collection of file utility functions

## Install

```shell
npm install @utility/file
```

## Usage

```typescript
import { exists } from "@utility/file";

await exists("./filename.txt");
// => true
```
